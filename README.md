## What it does

`main.py` writes exactly one job title to `/output/entry.txt`:

> **Pet Psychic for Grieving Goldfish Owners**

A real-sounding fringe job (pet psychic) with one hilariously specific,
low-stakes twist: the grieving clients own goldfish.

## How to run

```sh
python3 main.py
```

Deterministic, standard library only, offline, no randomness, no timestamps.
The output is byte-identical on every run.
